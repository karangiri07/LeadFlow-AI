Webhook Configuration Guide

  1. Go to developers.facebook.com > Your App > WhatsApp > Configuration.
  2. Set Callback URL to: https://your-public-domain/webhook (use ngrok if testing locally).
  3. Set Verify Token to: leadflow_verify_token.
  4. Subscribe to the messages webhook field.
  5. All incoming messages will trigger the RAG chatbot and appear in this admin panel!
